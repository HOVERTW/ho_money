# 📱 Ho記帳 - iOS 本地版本

## 🎯 版本說明

這是 **Ho記帳** 的 iOS 本地版本，專為注重隱私和離線使用的用戶設計。

### ✨ 核心特點

- **🔒 完全本地存儲** - 所有數據只存在您的手機中
- **🚫 無需登錄** - 打開即用，無需註冊帳號
- **📴 離線運作** - 無需網路連接，隨時隨地記帳
- **🔐 隱私優先** - 數據不上傳雲端，完全掌控您的財務資訊
- **⚡ 快速啟動** - 移除雲端功能，啟動速度提升 50%+
- **💾 輕量化** - 應用體積減少 30%+

## 🚀 快速開始

### 安裝

1. 從 App Store 下載「Ho記帳」
2. 打開應用即可開始使用
3. 無需註冊或登錄

### 首次使用

1. **開始記帳**
   - 點擊「+」按鈕新增交易
   - 選擇類型（收入/支出）
   - 輸入金額和分類
   - 保存即可

2. **管理資產**
   - 進入「資產負債」頁面
   - 添加您的資產（現金、銀行、投資等）
   - 系統會自動追蹤資產變化

3. **查看統計**
   - 在「總表」查看整體財務狀況
   - 在「圖表」查看詳細分析
   - 在「現金流」追蹤資金流向

## 💾 數據備份

### 導出數據

1. 進入「總表」頁面
2. 點擊右上角設置按鈕
3. 選擇「導出數據」
4. 選擇分享方式（AirDrop、郵件等）
5. 數據將以 JSON 格式導出

### 導入數據

1. 進入「總表」頁面
2. 點擊右上角設置按鈕
3. 選擇「導入數據」
4. 選擇之前導出的 JSON 文件
5. 確認導入即可還原數據

### 建議

- 📅 **定期備份** - 建議每週或每月備份一次
- 💾 **多處保存** - 將備份文件保存到多個位置
- 📧 **郵件備份** - 可以將備份文件發送到自己的郵箱
- ☁️ **iCloud 存儲** - 可以將備份文件保存到 iCloud Drive

## 🔧 技術架構

### 存儲方式
- **AsyncStorage** - React Native 官方推薦的本地存儲方案
- **鍵名格式** - `@HoMoney:*`
- **數據格式** - JSON

### 數據結構
```typescript
{
  "@HoMoney:transactions": [...],    // 交易記錄
  "@HoMoney:assets": [...],          // 資產數據
  "@HoMoney:liabilities": [...],     // 負債數據
  "@HoMoney:categories": [...],      // 交易分類
  "@HoMoney:accounts": [...],        // 帳戶列表
  "@HoMoney:user_preferences": {...} // 用戶偏好設置
}
```
